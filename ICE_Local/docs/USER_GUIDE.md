# ICE Local — operator guide

## Start

1. Extract the downloaded ZIP. Open `APP_PREVIEW.png` if you want to check the workspace layout first.
2. On 64-bit Windows, double-click the outer `START_ICE.cmd`. In PowerShell from the extracted outer folder, run `.\START_ICE.cmd`. If already inside `ICE_Local`, use `.\START_WINDOWS.cmd`. Keep its window open and use the browser page it opens. If needed, visit `http://127.0.0.1:8765`. This app uses bundled Python; do not run npm commands.
3. ICE opens directly to the local workspace. No account or internet connection is required. The server is available only on this computer at `http://127.0.0.1:8765`.
4. Click **Try sample files** to see one labeled synthetic General example and three research examples that need review, or import up to 50 ZIP packages at once. You can also import a folder or a set of PDF/XML/HTML documents. Uploaded files appear together in the **General queue**; matching findings remain visible on each article while extraction and XML generation run automatically. Click a file to open its editor; return to the all-files landing page from the workspace. The ZIP/folder headings and numbered file selector keep articles separate.

If files are skipped, open **Last import report**. If sources are ambiguous, choose the main PDF and the API, Scrapping and HTML documents manually. Each article must have a PDF. Missing support documents remain visible and cause review reasons.

## Review

The compact black-and-orange Dashboard can be collapsed with its top-right button to give the PDF and metadata editor more room. It shows package, General queue, informational issue and Exported counts. Select a numbered file to see its metadata entry count beside the file number, plus author/reference counts and verified checks. The metadata count covers populated core fields and individual keyword, author, affiliation, reference, email and ORCID values; it is not a quality score. All files stay in **General**. Matching findings and missing, conflicting, edited or uncertain evidence remain visible in Validation and Reports; General is not final editorial approval.

The left rail has three collapsible support widgets. View the document inside its widget, in the center panel, or in Large view. The comparison button supports support vs support, metadata vs support, metadata vs XML, and all sources. Metadata text is highlighted in XML and support sources; PDF line highlights locate matches, and the individual evidence buttons jump to an exact page and box. Use the full-screen buttons for the workspace, support rail, metadata pane, or a large dialog. Escape exits full screen.

The Audit tab lets you download the coordinate-aware PDF `extraction.json`, normalized PDF Markdown, parsed XML/HTML feeder JSON/Markdown, current metadata JSON and exact queue-check JSON. Use the original PDF for final interpretation. See `QUEUE_DEFINITIONS_AND_VERIFICATION.md` for the matching checks and tested examples.

On the right, edit metadata, inspect Validation and informational issues, edit references, and edit XML. Informational issues never block saving or export. The author editor includes given name, surname, initials, degree, source text, email, ORCID, correspondence and original affiliation links. Saving metadata writes the author degree as `ce:degrees` and regenerates XML from current fields. Numbered, lettered and single unmarked original affiliation blocks are detected in first-page front matter when their PDF layout is clear. Their author groups appear in the editor; the author-group editor permits repeated members while retaining global sequence. Review or add missing affiliations from the visual PDF. Link authors directly from each affiliation card. Switch the PDF viewer to **Capture document** for a readable text document reconstructed from the current PDF page, or stay in the image view. Select text across lines and right-click to copy or assign it into title, abstract, keywords, author fields, or structured affiliation fields. **Parse address + organization and add** runs the local address parser and fills organization, address, city, state, postal code and country fields. Selected affiliation text is kept in its affiliation `ce:text`; additional selected parts are appended as you assign them. Each assignment keeps its PDF page and position evidence; saving metadata regenerates XML. **Copy page text** copies the current page's selectable text. In References, keep the PDF source text and edit the XML full text separately. Select plain text in a markup field to add `<sup>`, `<inf>`, or `(Formula Presented)` where visually confirmed. An inline markup value must still read exactly like its plain field when tags are removed. The XML editor's type selector can wrap a selection in a tag; direct XML changes are retained as manual edits and require validation. **Browser preview** shows a light, Edge-style XML tree with expand/collapse, save and affiliation-group controls. Double-click a text value or an empty value between tags to edit it. Select text and right-click to wrap it in an XML tag, or right-click an element to add a nested tag. Use **＋ Affiliation group** to insert a complete author-and-affiliation group with editable empty fields. In the XML editor, inserting a tag with no selection places the caret between the opening and closing tags; the searchable tag menu groups document, citation, author, affiliation, abstract, reference and inline elements. Selecting text for an `affiliation` tag automatically places it in `ce:text`. Preview edits stay unsaved until **Save XML** is selected.

Save edits before switching files. Informational issue records preserve extracted findings and PDF evidence but never prevent XML export.

## Reports and exports

Open the standalone **Reports & Analytics** page for the General queue, informational issue summaries, package and matching-finding analysis, search/filter controls and all files, package totals, author/reference counts, matching findings and export status. Use row actions to open, download or delete one file. Select checkboxes to download multiple articles as one ZIP; choose whether to include original source documents. Export CSV for a spreadsheet ledger. **Export to folder** asks you to choose an authorized destination in a browser with the File System Access API; you may choose another destination afterward. If that browser feature is unavailable, download and extract the batch ZIP. Invalid XML remains labeled in output manifests; findings do not gate export.

Use **Clear file**, **Clear selected**, or **Clear all** only after keeping needed exports or a backup; these permanently remove local records and original copies for finished files. Processing files are skipped. Data lives in the extracted app's `data/` directory, which should be backed up before upgrading.

## Decisions that need people

The program does not fill missing reference information from elsewhere, infer uncertain corresponding authors from an asterisk attached only to an email, or claim a client XSD pass. Check footnotes, superscripts, affiliations, formulae, title differences, reference boundaries and informational findings against the visual PDF. Local OCR is available only if Tesseract is installed/configured. The app itself makes no production AI calls.
