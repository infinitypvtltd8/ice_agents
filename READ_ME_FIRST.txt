ICE LOCAL — WINDOWS QUICK START

1. Extract the complete ZIP. Do not run it inside the compressed folder.
2. Double-click START_ICE.cmd in this outer folder.
   From PowerShell in this folder: .\START_ICE.cmd
   From PowerShell in the ICE_Local inner folder: .\START_WINDOWS.cmd
3. Keep the command window open. The app opens at http://127.0.0.1:8765

This is a bundled Python application. npm start and npm install do not apply.
The full README and Markdown project guides are inside ICE_Local.

If replacing a previous extraction with saved articles, back up its
ICE_Local\data folder before installing this new copy.
